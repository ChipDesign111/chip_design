# 已选模型的真实数据与硬件联调报告

2026-10-13。模型来自 PR #2 的原始导出文件，版本 har-mlp-64x32x6-2026-09-24。采用现有 tiled V2；本次没有修改 RTL 或冻结外围，也没有重新训练、修改权重或量化参数。

## 真实分类准确率

官方 UCI HAR 测试集 2947 条，使用已保存的 64 特征下标与输入尺度：

| 实现 | 正确条数 | 准确率 |
| --- | ---: | ---: |
| 浮点导出模型 | 2520 / 2947 | 85.5107% |
| INT8 权重、浮点激活 | 2508 / 2947 | 85.1035% |
| 全整数 + ReLU/重新量化 | 2504 / 2947 | 84.9678% |

全整数相对浮点下降约 0.543 个百分点。与已有导出指标一致。主要误差为坐/站：201 条坐预测为站，146 条站预测为坐。混淆矩阵、标签和全部 SHA 见 [机器摘要](results.json)。

这些是所提供 checkpoint 在原测试划分上的复测；原训练流程用该测试集选择最佳 checkpoint，不是额外独立测试集结果。

## RTL 与完整 SoC

| 项目 | 实测结果 |
| --- | --- |
| NumPy INT64 与逐标量 Python 参考 | 2947 条全部逐值一致 |
| RTL 单次 | 2947 条 hidden/score/class 全一致，39 周期/条 |
| RTL 配对模式 | 同 2947 条再测一次，最后奇数条单次；全一致，双次 59 周期、重叠 18 拍 |
| RTL 合计 | 5894 推理，零硬件/参考差异；真实标签正确计数 5008=2504×2 |
| 真实 CV32E40P / AXI / NPU | 六类各 4 条，共 24 条、12 双次批，所有结果与整数参考一致 |
| CPU 程序 | 768 B 指令 + 5464 B 数据 = 6232 B；SRAM 8 KB 内 |
| 端到端 SoC 周期 | 76249，从原 TB 释放复位至 CPU 写 PASS magic，含装载/轮询/全部结果比较 |

24 条代表样例中模型对真实标签为 18/24；另外 6 条分类错误也必须且已经与整数参考一致。该小样本比例不作为总体准确率。原 NPZ 的 16 条全是站立，因此另取覆盖六类的 24 条。

还重跑初始 1000 组合成参数（3000 推理）、原核级/MMIO、四份原 SoC 镜像、tiled 八次/六次程序及 Yosys 通用结构检查。两类测试互补：真实模型验证接入，合成边界覆盖算术/状态极值。
