# 前一版与连续流水新版的整体对比

日期：2026-10-20。**主结论：相对前一版52be8c5，新版整机加速2.739×，权重已装载后的处理段加速3.441×。** 这不是新版内部20周期模式与去空泡模式之间的对比。

## 版本和测试口径

| 项目 | 前一版 | 新版 |
| --- | --- | --- |
| 硬件版本 | 52be8c57b365b70536500526a52905352e505666（PR #7 / main基线） | 8afc2e9e21436236704871e806a16b858dfb205b（PR #8 RTL） |
| 数值格式 | 原部署W8A8 | 已验证W8A4 |
| 推理批次 | 每次2条，12次命令 | 一次提交24条 |
| DMA读写 | 先读完整块，再写 | R/W流水，成功响应后提交输入 |
| DMA与计算 | 串行 | 输入预取与两级计算重叠 |
| 权重 | 同样2240 B、38个片上bank，装载一次后复用 | 同左 |

测试脚本通过`git archive 52be8c5 -- rtl`取出前一版真实RTL，在独立ModelSim库编译；没有用新版MODE0冒充旧硬件，也没有使用主工作目录中未提交的DMA修改。当前RTL与PR #8保持一致，本次只增加测试和报告。

两版使用完全相同的24个UCI HAR原始样本行，分别按各自原生数值格式推理。CPU均执行24次类别MMIO读取、24次结果暂存写入，并在统一的校验循环中执行24次类别比较（读取24个暂存值和24个金标准值）。测试台对两版都被动核对全部32个hidden、6个score及类别。不会因为旧版由CPU逐项检查hidden/score、新版只检查类别而人为放大加速比。

批次、地址布局和驱动不同，因此固件不可能是同一二进制；这里衡量完整版本收益，包括精度、传输、调度和驱动变化，并非孤立RTL算术加速。

## 完整SoC周期

| 测量范围 | 前一版周期 | 新版周期 | 加速比 |
| --- | ---: | ---: | ---: |
| 整机：CPU启动至相同自检完成 | **13619** | **4972** | **2.739×** |
| 应用：参数装载至自检完成 | 13375 | 4728 | 2.829× |
| 权重已装载后的处理/收集/校验段 | **11404** | **3314** | **3.441×** |
| 参数DMA设置、等待与完成检查 | 1872 | 1294 | 1.447× |
| 输入DMA等待片段之和 | 6708 | 606 | 11.069× |

输入DMA一项包含描述符配置、轮询、完成检查；旧版每条输入一次DMA，新版24条输入一次提交。11.069×不是32 bit总线的裸带宽增幅，也不能与并行计算时间直接相加。

portable-sram和授权RA1SHD两种后端的全部上述计数完全相同。代码分别788 B和644 B，含模型、输入和类别金标准的镜像分别4832 B和3904 B，均小于8 KiB主SRAM。

历史36571周期和3810周期对应不同软件校验工作，不能直接相除。本报告采用新的统一工作量基准，因此应使用13619/4972，不应把旧的1.010×内部消空泡结果当成版本间整体收益。

## 收益来源及代价

- 输入数据拍384→192，INT4使持续输入流量减半；参数搬运仍为598字。
- 总读/写数据拍各982→790，突发各62→50；DMA总引擎忙周期2708→1441。
- DMA命令从参数1次＋输入24次变为参数1次＋输入1次，减少CPU逐条配置和轮询。
- 前一版传输握手与计算发射同时发生的周期为0，新版为187，确认真实搬运/计算重叠。
- 新版支持连续样本发射，消除固定排空等待；FC1 32×4、FC2 6×2以及32路重定标数量不变。

**本地权重存储不是本次新增收益来源，因为两版都已经使用同一片上权重存储。** 上述2.739×是整套数据流和控制改进的合计收益。

W8A4相对原INT8模型有精度代价：原2947条测试正确2504条（84.9678%），新版正确2490条（84.4927%），下降0.4751个百分点。原checkpoint曾用该测试集选最佳模型，因此不是新的独立盲测。此处性能比较不代表同精度纯硬件加速。

## 证据与复现

数值与两版全部RTL SHA：[results.json](results.json)；测试脚本/模型/输入身份：[source_manifest.json](source_manifest.json)。CPU执行真实RV32I程序，经真实AXI和SRAM驱动DMA/NPU；测试台仅在CPU复位期间通过SRAM端口预装镜像，不预装NPU状态或注入完成标志。

```sh
# 仓库历史必须含52be8c5；浅克隆需要先获取该提交。

python test/2026-10-20/scripts/run_version_compare.py --memory ra1shd --vsim /path/to/vsim
```

仅为功能仿真周期；厂商SRAM关闭时序检查，无FPGA实测或目标工艺频率/面积签核结论。原新版内部模式比较仍保留为 [消空泡专项结果](../stream/report.md)，用于区分整体收益与单项优化。
