# EDA操作入口

本机总流程和命令见[当前EDA入口](../README.md)。默认运行完整功能→综合/34步→TT后仿→同DB SRAM STA→Lab5，不用旧版本目录或旧报告替代新输入。

每轮服务器uploads目录有自己的README.html及冻结work。常用分项命令为`python eda/remote.py status --upload 物理目录`、`python eda/postsim.py status --upload 后仿目录`及`python eda/signoff.py status --upload Lab5目录`。显式传入完整路径，避免本机last_*指针指向另一轮。

手工分段操作：先在服务器source /etc/profile.d/eda.sh，进入本轮上传目录，设置EDA_DEPLOY为该目录/deploy、EDA_WORK为该目录/work；按该版本README执行环境准备。随后参考[34步说明](讲义34步与文件对照.md)逐步续跑，禁止同时启动第二个工具进程修改同一work。

已完成物理输入的[后仿](后仿真操作指南.md)和[Lab5](Lab5操作指南.md)可独立续跑。RTL、SDC、库或物理配置变更需新上传重新实现；仅更改后仿平台可绑定原物理输入，但须记录平台与输入SHA。
