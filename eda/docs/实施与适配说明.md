# 当前SoC实施与适配

当前main是16-MAC/INT22、8KiB SRAM、顺序任务FC/量化激活及CPU/NPU编译部署。计算与复位的唯一说明见[当前架构](../../report/architecture.md)和[SRAM协议](../../report/sram.md)，本页仅描述修改边界。

| 修改内容 | 需要更新 |
| --- | --- |
| 支持范围内的模型/权重/输入 | 重新编译、量化、分块和SRAM布局；不改RTL |
| 新CPU算子 | 前端、整数参考和RV32内核；验证同整数语义 |
| 新NPU算子/阵列规模/维度上限 | RTL、ABI/编译器、参考模型与保护回归，随后全新EDA |
| SRAM型号/容量 | 存储适配、filelist、宏视图、供电/坐标、模型与编译布局 |
| 时钟、PVT、布局/面积、PAD | 新上传配置、新实现与同源SDF/Lab5；不得沿用旧输入 |

原专用权重布局为W1按输入对打包2048B，W2按4组48B有效权重打包并预留256B；通用布局由编译器生成，不能套用专用地址。总8KiB必须同时容纳代码与全部模型数据。

自动门控开启，原生library_enable保持，组合单元映射为tt_nonnegative_tables；配置implementation_effort=medium，setup_optimization_goal_ns=0.1是优化软目标。native_library_zero_slack最终要求Setup/Hold非负、TNS和负路径0，不能把软目标描述为验收门槛。当前analysis_profile只覆盖TT/SI关闭；扩展PVT必须独立测量。

完整操作见[EDA入口](../README.md)，结果只引用[本版验收](../../report/results/README.md)。
