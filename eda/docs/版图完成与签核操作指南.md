## 一键运行

```powershell
python eda/pipeline.py run --output /home/s2400011035/chip-fullstack-2026/eda_runs/完整新流程目录
python eda/pipeline.py run --only layout-signoff --eda-upload /home/s2400011035/chip-fullstack-2026/eda_runs/uploads/已完成物理版本 --output /home/s2400011035/chip-fullstack-2026/eda_runs/layout_signoff_本次新目录

```

pipeline 默认依次执行 RTL 检查/SoC 回归、综合与 01–34、TT 后仿及同数据库半周期 STA、版图完成与签核；`--only layout-signoff` 只调用最后一段。
`--start-at implementation`只省略命令内的RTL回归，保留来源检查并从全新Genus开始；若RTL已改，必须先完成并记录与该版本硬件SHA一致的功能/复位回归。本轮dea5584已在部署前完成对应回归，不能把此选项当作免验证。
2026-11-18 本轮物理部署 `fe04981` 已完成新综合、01–34、TT 后仿、同 DB SRAM STA 和版图完成与签核；结果见[全流程 EDA 结果](../results/fullflow_fe04981_20261118/README.md)。

完整上传、公共 unpack.sh 校验解压后，只启动版图完成与签核，不调用原 run_all.sh 重跑综合和布局布线。
run --detach只启动；status查状态；fetch --wait --output 新目录等待并校验回传。
`--upload` 显式选择版图完成与签核版本，`eda/dist/last_layout_signoff.json` 只保存本地最近位置。

## 本地/服务器分工

本地仓库维护正式程序、配置和文档；`eda/dist` 保存忽略的部署包；核验后小报告保存在输出目录；开发试验只在 archives。
每轮独立建立 `uploads/时间_layout_signoff_提交/soc-stu/layout`，从固定课程资源 `/lec/lab5/layout` 复制工程并记录所有原文件 SHA。本轮几何门禁为 Die `1940×1940 µm`、Die 到 Seal Ring 参考内框 `5 µm`、环单元向外占 `15 µm`、Seal Ring 外框 `1980×1980 µm`；任一边不满足即停止。
deploy 为完整冻结源码；`layout_signoff/config.json` 为冻结配置；`layout_signoff/inputs` 为原物理输入副本；`layout_signoff/evidence` 为命令、原始日志、摘要和 SHA。
soc-stu/layout/workspace保存私有OA、GDS及检查数据库；results保存结果和回传包。原物理work及共享PDK保持只读。
规则、授权模型、大GDS/CDL、OA、SVDB不入Git。物理源码提交与本轮程序提交分别记录。

## 执行和真实结果

核对物理34步/三阶段0、相同RTL、完整包SHA、GDS层次，执行原生V2LVS。
随后私有preDummy装配、OA导入、preDummy DRC、两种Dummy、合并、最终OA导入、DRC、LVS/ERC、天线及WB串行执行。
几何自动化读取原生GDS中的edge/corner按1µm节距装配，不缩放、不flatten功能子层次，记录原生子单元元素计数。
按DEF测量尺寸并单列最终含环外框；POC锚点需在实际PVDD2CDG M3导体内。实现及解析必须经实际工具运行验证。
流程依赖项目 `tools/layout_signoff_python` 中的 Python 3.12、gdstk 0.9.61、numpy 2.2.6；原生 Calibre/Virtuoso 环境照常使用。
存储预算统计整个 `uploads` 项目目录并预留 6 GB 峰值增量，上限 20,000,000,000 字节；IDE/工具缓存不计入项目预算。重任务串行，保留最新有效物理与 TT 结果。
