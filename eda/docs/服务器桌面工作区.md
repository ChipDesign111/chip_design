# 服务器桌面工作区

服务器固定入口为 `~/Desktop/fullstack_chipdesign`，在桌面文件管理器打开该目录，双击 **README.html**。它是独立UTF-8网页，不需要网络，包含目录作用、当前工程、阶段状态及报告链接；README.md提供相同的文本说明。

```text
fullstack_chipdesign/
├── README.html / README.md  GUI/文本使用说明
├── deploy/                 当前正式部署：server、rtl、docs、source.json
├── configs/design.json     准备前选择的本轮参数
├── runs/w8a4_日期_时间/     一轮完整实现的全部输入、数据库、报告和最终视图
├── current_run.txt         当前工程绝对路径
├── run_env.sh              当前工作区、部署、配置和运行路径
├── run_all.sh              完整综合、01–34及结果打包；同工程支持续跑
├── collect_results.sh      已完成实现后重新收集结果
├── logs/                   完整入口的控制台输出
├── results/current_run.json 当前步骤、最终时间/物理/导出检查摘要
├── docs/                   操作指南、34步说明、基础知识和报告分析
├── incoming/               上传包接收区，部署成功后可清理
├── lab4/                   保留的原Lab4工程、资料和辅助文件
└── history/                历史有效结果，非本轮输入
```

部署命令按[操作指南](操作指南.md)执行。解压后首次建立或刷新桌面入口：

```bash
cd "$HOME/Desktop/fullstack_chipdesign"
bash deploy/server/bin/workspace.sh
```

该命令只建立入口、复制文档并读取当前结果，不启动商业EDA。已有配置和current_run.txt保留，不会偷偷选择另一轮。结束时自动刷新README；中途需要刷新时也可再执行一次。运行中的阶段可能尚未生成结果，不能把缺少数据当作通过。

在tmux终端里运行或继续整轮：

```bash
cd "$HOME/Desktop/fullstack_chipdesign"
source ./run_env.sh
bash ./run_all.sh
```

首次从RTL综合开始；同一工程再次执行按已通过步骤续跑，不导入其他工程的开发检查点。完整all结束后自动生成报告、核心交付包与轻量回传包。无需再次手动prepare。

需要另起一轮时，先确认旧任务退出，修改current_run.txt为runs下一个尚不存在的新目录，再执行workspace.sh刷新run_env.sh。参数在configs/design.json准备前确定，旧工程使用自己的冻结配置。

Lab4原始内容完整保留。历史迁移的报告和数据库含原绝对路径，保留原记录，不将旧证据改写成当前结果；不要把history当成可随意继续运行的当前工程。新运行只使用deploy、configs和runs。课程PDK及SRAM仍读取/lec共享目录。

结果定位、轻量下载和清理方式见[报告查找与分析](报告查找与分析.md)及主指南10.1节。运行目录内的最终GDS/SDF/SPEF和检查点保留在服务器；中间文件由正常阶段覆盖和管理。
