# 当前TT门级后仿

后仿必须使用已完成同源34步的版后网表和SDF。绑定正确不等于功能或时序通过，三类结论分别检查。

```powershell
python eda/postsim.py run --eda-upload /home/s2400011041/Desktop/fullstack_chipdesign/uploads/本轮物理目录 --simulator vcs --sdf-mode tt --extra-firmware-dir report/results/optimized_functional/postsim_payloads
python eda/postsim.py status
```

run创建独立上传、导出物理视图、记录输入SHA和实际工具命令，不修改原work。默认16个原有固件加7个带逐字校验的新任务固件，形成23例SDF与1例无SDF对照；run_plan.json记录实际矩阵。仿真器采用原生STD/IO/SRAM模型，NTC、RECREM、notifier及全部阶段时序检查保持开启。

```powershell
python eda/postsim.py timing --upload /home/s2400011041/Desktop/fullstack_chipdesign/uploads/本轮后仿目录
python eda/postsim.py fetch --upload /home/s2400011041/Desktop/fullstack_chipdesign/uploads/本轮后仿目录 --output C:/Users/zixiang/OneDrive/Desktop/advanced_chip_study/lab5/本轮后仿核验
```

先等results.json完成，再只读加载同一DB检查SRAM输入/输出半周期及复位到请求路径。fetch核对压缩包、逐文件SHA，生成audit.json，分别列出功能、回标错误/缺失、负延时截零及动态违规。模型Warning不要求全零，不能据功能PASS忽略真实时序事件。

POR相位矩阵保留。NDM通过真实DMI DMCONTROL写入并从响应FIFO读回，不强制同步寄存器输出作异步跳变。上电模型初始传播的设置不是屏蔽最终复位检查。

本版只验收TT，回标错误、缺失、负IOPATH截零及全部阶段动态违规为0；原专用SDF观测2701拍与旧版同口径一致。pvt-min/pvt-max仅在相应角视图和匹配库实际导出后才可使用，不从本版TT结论推断快/慢角已通过。[当前结果](../../report/results/README.md)。
