## 2．面积是否真正达标

Die 是含核心和 PAD 外围的整个裸片；Core 是内部摆放逻辑的区域；Cell Area 是库中单元面积之和。不能用后两者代替整颗面积。

| 项目 | 本轮值 | 怎么理解 |
| --- | --- | --- |
| 实际 Die | 1996.4×1996.4 µm | 工具合法网格对齐后的尺寸 |
| 含PAD面积 | 3.98561296 mm² | 1996.4² / 1,000,000 |
| 验收上限 | 4.0 mm² | 用户最终确认的整颗面积限制 |
| 面积余量 | 0.01438704 mm²，约0.360% | 余量小，新增PAD或改尺寸要重验 |
| 核心请求/边距 | 1696 µm / 四侧150 µm | 请求值不直接冒充实际外框 |
| 综合 Cell Area | 1,894,546.189 µm² | 完整SoC映射面积，包含一个SRAM |
| SRAM | 401,443.591 µm² | 原生2048×32，8 KiB |
| 综合标准逻辑 | 1,493,102.598 µm² | Cell Area减去SRAM |
| 最终报告密度 | 63.089%；含Filler时100% | Filler填空隙，不代表新增计算能力 |

首轮 INT8 综合 Cell Area 为 2,171,670.432 µm²，本轮减少 277,124.243 µm²，约12.76%。移除了交叉开关内部额外流水寄存器，并让70个INT8乘法器直接进入INT32累加器；CPU、DMA、端点寄存适配器、主SRAM及指定并行度保留。旧版1500 µm核心规划失败，没有实际裸片结果，不能把旧单元面积当作旧Die面积。

## 3．时序是否通过，瓶颈在哪里

寄存器输出经过逻辑和导线，必须满足下一个采样边沿。Setup检查能否及时到达，Hold检查是否变化过早。WNS是最差余量，TNS是所有负余量合计；0.001 ns等于1 ps。

| 最终检查 | WNS | TNS | 违规路径 |
| --- | --- | --- | --- |
| Setup | +0.042 ns（42 ps） | 0 | 0 |
| Hold | +0.021 ns（21 ps） | 0 | 0 |

Setup最差路径在CPU：`id_stage_i/alu_operator_ex_o_reg[4]` 经执行级ALU组合逻辑，回到 `id_stage_i/alu_operand_b_ex_o_reg[12]`，使用sys_clk。Required Time=21.182 ns减Arrival Time=21.140 ns，余量0.042 ns。这些时间包含真实时钟树延迟，不能把Arrival直接当作周期。

Hold最差路径在JTAG：`i_dmi_jtag/data_q_reg[11]` 到 `i_dmi_cdc/i_cdc_req/i_src/data_src_q_reg[data][11]`，使用jtag_clk，余量0.021 ns。系统周期仍为20 ns；独立JTAG周期100 ns，虚拟JTAG参考1000 ns用于IO约束。沿用原复位及跨时钟约束，没有为本轮违规新增路径例外。

最终max_cap、max_tran、max_fanout、max_length的Real/Total均为0：负载电容、信号变化时间、扇出和长度没有已报告违规。42 ps和21 ps都是较小余量，结论仅适用于 **TT、1.8V、25°C、SI关闭、原生CapTable low RC** 条件，不延伸为全部工艺/电压/温度均通过。

## 5．功能、DMA并行与启动保护

本轮84项RTL/头文件/filelist哈希与已通过功能验证的输入一致，且与回传的部署源码一致。32组随机批次及12组训练双样本批次（24条UCI输入）逐值通过；完整CV32E40P SoC使用授权SRAM行为模型和可移植模型均通过。

第一层每拍2输入、更新32输出，共64个INT8乘法器；第二层每拍1输入、更新6输出，共6个。输入、权重和隐藏激活为INT8，偏置、累加和分数仍为INT32。两个64B tile缓冲交替接收DMA权重；当前tile完成本批全部样本后才允许替换。完整SoC实际DMA读/MAC重叠62拍、写/MAC重叠93拍，不是仅同时使能模块。

CPU自检在提交启动后的观测耗时3659拍，包含软件与检查开销，不是纯NPU推理延迟。ASIC默认禁止CPU取指：2048个SRAM全字顺序装载完成后，向Boot MMIO `0x0001003c` 写入密钥 `0xb007c0de`，再等待5拍余量才允许执行。部分装载和错误密钥不能提前放行。系统复位异步拉低，分两级各4拍同步释放；复位、DMA中断和重启等测试通过。运行中重装载前需停CPU或复位，撤销密钥本身不等于硬复位。

功能证据见仓库 `report/functional_validation.json`。授权SRAM行为模型测试关闭时序notifier；这不是SDF回标后仿。
