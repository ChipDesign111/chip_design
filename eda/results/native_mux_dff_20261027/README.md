# 普通DFF实现：四库角EDA与三组SDF最终结果

2026-10-27完成。物理输入`4427c4b`以20ns完成同源34步，环境、EDA、整理及入口退出均0；含PAD整颗 **3.7956390976mm²≤3.8mm²**。随后对该版数据库完成TT、FF−40快角、SS125慢角三组后仿，每组16例SDF和1例独立零延时对照，全部通过功能、绑定和全阶段动态时序审核。main仍为`d40b217`；本轮后续修改只在xzx。

## 1．本轮修改与实际效果

RTL与main逐文件一致，包括完整CV32E40P、64+6个INT8乘法器、INT32累加/偏置/分数、8KiB SRAM、两个64B权重tile、整批复用、DMA/计算并行及启动/复位保护。修改的是综合/后端的实现选择：禁止自动插入门控，并用普通DFF前的数据选择器实现寄存器使能。DFF在时钟边沿存储数据，MUX根据使能在“新数据”和“原值”之间选择；不使用库触发器内建E/SE控制实现功能保持。

`register_mapping.tcl`必须在Genus的`init_design`建立活动库角对象后重新应用；只有初始化前设置会遗漏后建对象。实际[综合证据](synthesis.json)确认自动门控0、受控触发器0、锁存器面积0、原生SRAM1个，NPU/DMA层次存在。此处检查的是所选硬件是否真的生成，没有增加正余量门槛。

## 2．静态时序、面积与物理

Setup要求数据在采样沿前到达；Hold要求采样沿后仍稳定。WNS是最差路径剩余时间，TNS汇总全部负余量。按用户正常条件：各角WNS≥0、TNS及违规路径均0；不另加100ps Hold、200ps Setup或人为边沿门槛。1ns=1000ps。

| TT25 | +4.062 | +0.115 | 0 / 0 |
| SS125 | +0.001 | +0.289 | 0 / 0 |
| FF0 | +5.743 | +0.029 | 0 / 0 |

全局Setup/Hold最差 **+0.001/+0.020ns**。[33步](steps/step_33.json)对应Filler后最终检查；[34步](steps/step_34.json)对应导出完整性。电气违规、default DRC、未解决信号/核心PG连通及天线违规为0；IO抽象供电残项仅按同源22步原生几何证据分类，不能当独立LVS。实际RC温度25/125/0/−40°C见[读回](rc_temperatures.json)。

Die外框1948.24×1948.24µm；综合单元面积2039855.258µm²，其中SRAM401443.591µm²。实际逻辑密度 **74.138%**；规划/优化预算85%，包含Filler的100%不是逻辑密度。外框固定，逻辑面积增加不直接增大Die。

## 3．动态后仿及复位

SDF给出实际单元和连线延时；后仿让真实门级网表带着这些延时执行固件。检查初始化、工作和最终复位全部阶段，消息、notifier、NTC/RECREM和负检查保持开启。不是只检查正常计算窗口。首组最终复位偏移2ns，其余覆盖0.25–19.85ns；全部仍以20ns运行。

| SDF模式 | 功能用例 | 全阶段动态事件 | 回标error/缺失 | 负IOPATH截零消息 |
| --- | ---: | ---: | ---: | ---: |
| tt | 17/17 | 0 | 0 | 18 |
| pvt-min | 17/17 | 0 | 0 | 438 |
| pvt-max | 17/17 | 0 | 0 | 0 |

快/慢角使用同一个跨角SDF的MINIMUM/MAXIMUM，分别来自FF−40/SS125；TT使用独立TT文件，FF0有静态检查，没有额外宣称FF0专用SDF。每种17例中只有独立`gate_zero`对照使用NO_SDF、notimingcheck和delay_mode_zero；16例SDF不使用这些选项。每组通过CPU、隐藏层、6个分数与类别逐值自检，NPU1035拍，DMA读/MAC重叠62拍、写/MAC重叠93拍；CPU启动后观测3660拍含测试开销，不等于纯NPU延迟。

本次TT此前的6条自动门控和30条E/SE最终复位事件均未出现。证据只支持这份实现及所测相位/输入，不证明任意时钟与复位波形下无条件安全。系统复位期间时钟需要继续运行，已接受SRAM访问完成一次，后续新请求停止。

## 4．SRAM半周期路径

系统上升沿先寄存命令，反相时钟让SRAM在系统下降沿执行，下一系统上升沿接收响应。可用时间约半个周期10ns，不能把它误按完整20ns检查。同一step34数据库只读STA保留传播时钟和真实反相单元，0ns上升、10ns下降、下一20ns上升的关系可在原报告核对。

| 路径 | Setup/ns | Hold/ns |
| --- | ---: | ---: |
| 输入寄存器→SRAM | +2.044 | +9.876 |
| SRAM→响应寄存器 | +0.176 | +10.917 |

上述各报告列20条最差路径，取其最小值；源报告为四活动角读取后的当前分析结果，路径自身标明实际角，不能把这4个数理解成每角单独的20条检查。[输入Setup](sram_input_setup.rpt)、[输入Hold](sram_input_hold.rpt)、[输出Setup](sram_output_setup.rpt)、[输出Hold](sram_output_hold.rpt)及[传播时钟](sram_clocks.rpt)保留原文。读取未ECO、未保存修改数据库。

## 6．警告和验证边界

本轮正常条件下EDA/SDF通过，不表示所有工具限制已消失。TT有18条、快角438条负IOPATH截零消息；快角另有34条ANIOD调整消息，`negative_path_delay_support_complete=false`如实保留。慢角0条截零不表示没有其他Warning。SWC/IWSBA/UHICD等原生消息及输入PAD时间0消息保留分类；不手改SDF、不关闭检查来消警告。因存在负延时建模损失，不能称完整延时无损或晶圆厂全签核。
