## 检查结果如何理解

Setup/Hold均WNS≥0、TNS=0、违规路径0；电容、转换时间、扇出和线长违规均0。最终无未摆放逻辑；完整核心VDD/VSS供电连接、默认DRC和天线检查通过。IO的VDDPST/VSSPST两项抽象限制仍依同源22步原生几何证明分类，不当作独立LVS通过。

本版SRAM输入寄存器到宏、宏到响应寄存器只有半个系统周期。这些路径不能用20ns全周期推算，也不能增加假路径豁免。最终全局STA通过；补充只读STA确认输入半周期Setup/Hold +6.290/+10.194ns，输出 +3.188/+11.476ns，见[路径原文与解释](postsim/README.md)。

导出检查：57098个非顶层SDF实例对应、63677个SPEF网络、616个GDS结构，未定义GDS引用0。导出SDF不是执行SDF后仿。
