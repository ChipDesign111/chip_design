# HAR tiled V2 验证报告

2026-10-13。代码采用 2 个 FC1 tile（各 16×4）、1 个 FC2 tile（6×2），同步 banked 权重存储和跨样本两级流水。原 Lab 3 外围和原回归材料 90 文件 SHA 一致。

## 实测结果

| 测试 | 结果 |
| --- | --- |
| 原核级/MMIO 三组测试 | PASS |
| HAR 核级 1000 参数/输入组 | 每组单次 + 双次，共 3000 推理，hidden/score/class 全部逐值 PASS |
| HAR MMIO 12 组 | 单次/双次、状态、忙时写、非法配置、字节排列、同步回读、重叠时 CPU 读取两个权重 bank PASS |
| 复位 | FC1、FC2、两级重叠时中断并重新装载 PASS；RAM 旧数据被有效位屏蔽 |
| 原 CPU test1/test2/test3/hand | PASS，分别 7432/14754/20804/208 SoC 周期 |
| 新 CPU 六单次 + 双样本 | 八次推理 PASS，56775 SoC 周期；39/59、18 重叠、38/38 阶段计数正确 |
| CPU 六单次性能程序 | PASS，51049 SoC 周期；V1 同六输入为 64475，周期比 1.263（减少约 20.8%） |
| Yosys 通用结构 | 无检查错误、无锁存器；38 RAM / 17920 bit / 76 同步读口 / 140 点积乘法器 + 32 量化乘法器 |

单样本核心 39 周期；两样本流水共 59 周期，比串行两次 78 周期少 19（约 24.4%）。从第一结果到第二结果间隔 20 周期。初始 V1 为单样本 2279 周期，计算周期比约 58.44 倍；这不是同频实物测速结论。

双层各样本活跃 19 周期，TB 独立观察重叠 18 周期，并核对硬件计数，避免只凭“两模块”宣称流水。

[机器摘要](tiled-v2.json) 记录最终 SoC 周期、向量/firmware SHA、各文件 SHA、工具版本、结构检查结果与性能比。历史 [V1 报告](baseline.md) 保留，不作为新代码结果。

## 运行

```text
python scripts/check_repo.py
python scripts/run_tests.py --unit
python scripts/run_tests.py --soc --vsim "本机 vsim 路径"
python scripts/check_synthesis.py
```

完整 SoC 为 ModelSim + 真实 CV32E40P + 固定 AXI，不是核级或直接强制写 PASS。
自检镜像八次推理占 6904 B；六次比较镜像占 6908 B；主 SRAM 8 KB，测试标志区 0x1FE0–0x1FFF。两份均由可复现 RV32I 编码器构建，不依赖 GCC。

单次性能程序采用与 V1 相同的六输入、权重、偏置、量化和逐项比较，并跳过新增 batch；多一个跳转，未减去其开销。八次程序与 V1 六次程序工作量不同，不拿它们直接计算加速比。CPU 数据装载/读取占比较高，端到端收益远小于核心周期比。

## 限制与取舍

2:1 为 tile 实例数量比，实际点积乘法器比 128:12，面积并非两倍；32 路量化也消耗额外逻辑。
bank 很浅，最终未必映射到 FPGA BRAM；寄存器、端口和路由开销未做目标平台面积评估。通用 Yosys 统计不使用 PDK，不是商业综合/STA/DRC/LVS/Antenna。没有测得的目标频率和功耗。

当前批次长度只支持 1 或 2，模型/偏置/量化在一批内共享，BUSY 时 CPU 写拒绝。没有 DMA、无限长队列、CPU 装载与计算重叠。权重为合成测试数据，真实人体活动识别精度尚待训练模型与数据验证。
