# 2026-11-19：FPGA 外部工作区迁移验证

以 `19a0ce2` 为迁移前基线，将活动 Vivado 工程、固件及完整历史归档移到仓库同级 `fpga_workspace`。仓库仅保留板级源码、默认配置、可重建流程、生成/测试脚本和轻量报告；硬件逻辑没有修改。

已完成的核验：

- 403 份原 Git 跟踪资产在迁移后按大小和 SHA-256 全部一致；迁移前收据、原 XPR 和原固件副本保存在外部 `migration/`。
- 用现有 Python/PyTorch 环境在外部重新生成 62 个正常镜像；182 份生成的 `.hex/.bin/.S` 与迁移前逐字节一致，另 1 份历史不完整装载 fixture 保留原字节，不由当前生成器重建。
- 16 项批测脚本离线检查通过，覆盖 62 镜像流程、错误结果、通信、部分失败、中断和报告文件短暂/持续占用。
- 9 项工作区检查通过，覆盖外部输出约束、GDB 路径引用、迁移后工程引用、本机配置保留、报告收录与防覆盖。
- Vivado 2019.1 在全新外部目录 `verification/new_machine_v2` 创建工程及 Clock Wizard 成功；对应输入 SHA 和工具日志保存在该工作区 `logs/project_*/`。
- 仅含 3017 份 Git 跟踪文件的副本完成仓库及 75 项硬件 SHA 检查，重新生成 62 份固件、运行上述 25 项离线检查，并成功创建外部 Vivado 工程；不依赖旧工程、固件或本机未跟踪源码。
- 原活动工程也已成功在新位置打开，87 个文件引用全部有效。时钟 IP 的输入 100 MHz、输出 20 MHz、无 reset/有 locked 配置与迁移前一致；工具刷新 XCI 前的原件也另存于外部迁移目录。

工程创建验证没有执行综合、实现或生成新 bitstream。本轮也没有连接真实 FPGA；用户手动板测和历史 PPA 分别见[当前测试状态](../../TEST_REPORT.md)与[历史报告索引](../README.md)。
