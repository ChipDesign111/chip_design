# 2026-11-21 静态姿势个人校准与真实板测

旧HOF前端主要度量运动，用户保持姿势后特征减弱。新版在PC使用固定官方YOLO11n-pose提取可见身体关节，生成64维静态坐标、骨向量与缺失mask，再由FPGA的64→32→6 INT8网络分类。RTL、20MHz时钟及冻结bitstream未变，PC不生成动作类别供显示冒充硬件结果。

12段现场视频按真实稳定姿势人工检查后，205帧参与个人校准，另加旧TRAIN150帧。两轮个人片段均入训练；相机调整与无法辨认目标姿势的区间不用于训练，完整原片与转换诊断本机保留。旧52帧仅作开发检查，其中缺少右臂类别。没有构造新的独立测试集，没有按相邻帧随机拆分来报告准确率。

- 个人稳定姿势INT8校准拟合：200/205（97.56%）；这是训练数据拟合。
- 旧开发检查：32/52（61.54%）；此前已经参与开发，不能代表新用户或独立泛化表现。
- 真实JTAG回放：407组输入的六路INT8分数全部与冻结后重建的整数参考一致，序号与执行计数连续。
- FPGA包标签`e8a18d0b9e0da70a`；8KiB镜像、剩余SRAM3936字节，仍有真实RAW NPU计算。
- 显示需连续结果与分差门槛；筛选减少跳变，不构成模型准确率提升。

聚合数值、来源和文件哈希见[summary.json](summary.json)。视频、图像、逐帧输入、逐帧输出和私人训练权重不上传。板上数值一致性只能证明部署计算正确；真实实时识别效果仍需现场动作验证。此前[HOF40.4%记录](../camera_flow_20261120/summary.json)保持原样，两版数据范围不同，不能直接相减。
