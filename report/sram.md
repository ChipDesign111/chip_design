# SRAM、启动和复位

主SRAM为2048×32、8KiB单端口宏。chip_sram_2048x32默认行为后端，可通过CHIP_USE_RA1SHD选择授权宏。ASIC上电数据未知，复位不清空SRAM。

my_mainmem在系统上升沿接收命令并寄存地址、数据、字节掩码，SRAM在反相时钟的随后下降沿执行，读结果在下一上升沿响应。payload无异步清零，复位期间已接受访问仍完成一次，后续停止新请求。宏输入/输出都检查真实半周期，不加假路径绕过。

POR/NDM请求先两级下降沿采样，再经上升沿重定时进入rstgen；功能复位共同控制CPU、AXI、NPU及SRAM事务入口，释放在下降沿。请求需保持两个下降沿及紧接的上升沿，保守识别延迟为2.5T（20ns时为50ns），系统时钟必须持续运行。独立JTAG TAP复位保留，NDM不清除独立POR/debug域。该协议不承诺任意异步相位零亚稳态。

CPU上电不取指。经Debug SBA顺序写满0x80000000–0x80001ffc的2048个完整字，建议读回校验，再向0x0001003c写密钥0xb007c0de。Boot检查完整覆盖，经5拍余量后放行CPU。部分字节、乱序、半份程序、错误时机密钥不能放行。重新装载需停机/复位并重新提交。

原专用固件使用固定布局；编译器镜像由manifest.json统一描述机器码、权重、LUT、任务表和张量地址，总量不得超过8KiB，不能直接套用旧专用地址。Boot的0x00010038提供SoC周期计数，从CPU首次取指计到PASS/FAIL提交冻结，不包括镜像装载和debug等待。

复位或DMA错误会撤销任务输出有效性，已写的SRAM部分数据不会回滚，恢复程序必须重新生成该输出。当前同DB SRAM六类STA及23例SDF均通过，具体数值见[验收](results/final_result.json)。
