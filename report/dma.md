# 权重 tile DMA

har_dma 是 AXI4 增量突发引擎；har_dma_axi 仅适配总线元数据。读 SRAM、写 NPU tile 窗口，AW/AR 独立握手，两字 FIFO 对读写速度差提供背压，不再先缓存完整 16 字突发才写。每次突发最多 16 字，跨 4KiB 边界自动拆分。

NPU 发出自动描述符：第一层 src=W1_BASE+tile×64、len=16 字；第二层 src=W2_BASE+tile×8、len=2 字；dst=0x70000100+bank×64。目的 bank 必须空闲。完整一批传输 2048+256=2304B，不因 batch=2 重复装两遍。下一批重新从 SRAM 装入，可由软件在批次间更新模型。

在本批所有样本用完当前 tile 前不会释放它。另一 bank 预取可与 MAC 并行；块发布要同时满足预期字全部收到、DMA 完成且无错误。读响应错误、写响应错误、RLAST 不符都记错误，失败数据不发布。提前 RLAST 时用零补齐已发写突发后失败，避免破坏 AXI 已接收的写事务。真实 AXI 对端仍必须最终响应；硬件不臆造失联对端的完成信号。

调试 CSR 以 NPU+0xd00 为基准：0 控制 START/ACK，4 DONE/BUSY/ERROR，8 源地址，12 目的地址，16 字数，20 周期，24 已复制字数，28 错误码。CPU 手工 DMA 只允许 NPU 空闲；正常推理由自动描述符驱动。

完整 SoC RTL 测试已观测到实际读/MAC、写/MAC 各 62 拍重叠。计数只统计总线完成握手且乘积有效的同拍，不把 BUSY 期间都当计算并行。
