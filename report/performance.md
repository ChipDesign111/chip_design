# 本版性能

原始专用程序保持2700拍；同口径SDF旧/新均2701拍。硬件Boot计数为2695，三种计数边界不混用。

| 同网络/同整数规则 | 旧通用路径 | 当前路径 |
| --- | ---: | ---: |
| mixed0 | 3724 | 2521 |
| wide0 | 2044 | 1042 |
| output_tiled0 | 1959 | 906 |
| trained_har0 | 4019 | 1727 |

MAC阵列没有扩大。收益主要来自自动输入/bias与结果交接、硬件量化/激活、内部转发和减少CPU调度。小到1→1时选择CPU105拍，避免启动NPU抵消收益。
