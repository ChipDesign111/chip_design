编译器默认使用顺序任务引擎，`--legacy-npu`保留旧路径。新硬件增加自动输入/bias、精确量化及六种激活、掩码写回、内部交接和多层任务；沿K/N分块、CPU边界和特化选择由编译器生成。[使用方法](../../compiler/README.md)；[任务ABI](../../compiler/TASK_ABI.md)。不支持且没有已注册CPU内核的算子仍明确拒绝。
