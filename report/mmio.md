# 最终版 MMIO

NPU基址0x70000000，16 KiB窗口，32 bit对齐访问。详细软件时序见 [流水设计](streaming.md)。

| 字节偏移 | 用途 |
| --- | --- |
| 0x010 / 0x014 | 重定标M=39986 / SHIFT=24，仅空闲改写 |
| 0x100～0xA57 | 560字权重、32字FC1偏置、6字FC2偏置 |
| 0xD00～0xD1F | DMA控制、状态、源、目的、长度和计数 |
| 0xE00～0xE3F | DMA输入暂存，成功响应后才提交 |
| 0xF00 | ARM批次 |
| 0xF04 | bit0 DONE / bit1 BUSY / bit2 ERROR |
| 0xF08 | 样本数1～64 |
| 0xF0C | 固定流水配置3；其他写入值报错，无运行模式切换 |
| 0xF10 | ARM至完成的周期（含等待） |
| 0xF14 / 0xF18 | FC1 / FC2有效发射周期 |
| 0xF1C | 两层同时发射周期 |
| 0xF20 / 0xF24 | 接收 / 完成样本数 |
| 0x1000～0x10FF | 64个按顺序保存的类别槽 |

先装载参数并配置M/SHIFT、样本数，再ARM，最后启动输入DMA。源32 B对齐、长度8×样本数个32 bit字，目的0x70000E00。软件轮询DONE/ERROR必须设超时。DMA完成前不得改源数据，NPU忙时不得改权重与配置。错误批次丢弃并全局复位恢复；不能把错误包当有效数据。
