# NPU MMIO

基址 0x70000000；下表为字节偏移，CPU 使用对齐 32 位访问。addra 端口内部使用字地址。输入、偏置和参数在空闲时配置；BUSY 或 DMA 忙时禁止改写。未定义读返回零，非法写置 ERROR。

| 偏移 | 功能 |
| --- | --- |
| 0x00 | CONTROL：bit0 START，bit1 ACK |
| 0x04 | STATUS：bit0 DONE，bit1 BUSY，bit2 ERROR |
| 0x08 | 样本 0 类别 |
| 0x0c | 本批 NPU 周期数，含等待权重 |
| 0x10 / 0x14 | MULT / SHIFT |
| 0x18 | 批次大小 1 或 2 |
| 0x1c | 实际 DMA 读或写握手与乘积累加重叠的周期 |
| 0x20 / 0x24 | 第一层 / 第二层 SRAM 权重基址 |
| 0x28 / 0x2c | 两层 MAC 发射周期，分别为 batch×32 |
| 0x30 | 完整装入 tile 数，成功一批为 64 |
| 0x34 / 0x38 | DMA 读 / 写握手分别与乘积累加重叠的周期 |
| 0x40–0x7f / 0xc00–0xc3f | 样本 0 / 1 的 64 个 INT8 输入 |
| 0x100–0x17f | 两个 64B tile bank，仅供 DMA 预取；不是整模型权重窗口 |
| 0x9c0–0xa3f / 0xa40–0xa57 | 32 / 6 个 INT32 偏置 |
| 0xa80–0xa9f / 0xc40–0xc5f | 样本 0 / 1 隐藏结果 |
| 0xb00–0xb17 / 0xc80–0xc97 | 样本 0 / 1 的六个 INT32 分数 |
| 0xc98 | 样本 1 类别 |
| 0xd00–0xd1f | DMA 调试控制和状态 |

权重基址必须 4 字节对齐且整个第一层 2048B、第二层 256B 位于 0x80000000–0x80001fff。权重字节按小端打包；完整布局见 [DMA](dma.md)。START 后硬件自主提交 64 个描述符，不需要 CPU 一块块轮询搬权重。
