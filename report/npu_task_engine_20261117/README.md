# 顺序任务NPU：分阶段实现记录

按用户七阶段要求执行。阶段一基准和阶段二软件协议已冻结；新增硬件、编译器的功能原型已跑通，仍需查表缓存方案比较、完整性能/面积和EDA验收。

基线为94636cc，已验收物理346e467、TT/Lab5 bf2ff30；原开发分支保留。本轮隔离在feat/npu-task-engine工作树。

[阶段一周期、流量与冻结基准](stage1/README.md)；[机器可读结果](stage1/summary.json)；[阶段状态](state.json)。

阶段一：8组既有模型的全部8KiB镜像与原冻结包逐字节相同；6组FC尺寸分别运行真实CPU/NPU并核对整数输出，1→1还核对无探针对照。原四样本2700拍、硬件2695拍、NPU952拍保持。此阶段没有修改RTL。

混合网络的3719个硬件周期中，NPU ISSUE24、权重未就绪176、就绪控制15；CPU输入/bias/结果搬运622、配置/启动82、量化循环550、激活阶段1070、逐元素阶段1118，其余62。各项按已接收指令时间边界及NPU状态分账，不把CPU量化等同于纯乘法器忙周期。R数据未返回与权重未就绪交集39拍，不能把176拍全部称为AXI读等待。原专用NPU952拍则为ISSUE576、量化128、排空2、Argmax20、权重未就绪192、就绪控制34。

1→1单任务现有NPU175拍、CPU105拍，说明小尺寸需要保留CPU后端选择。具体流量区分CPU有效字节、SRAM32位实际命令、DMA两端及逐张量次数，避免重复加总。

新增实现：64B任务ABI、自动输入/bias、INT22 FC、精确INT22×INT32缩放、六种激活、复用h缓冲、带字节掩码/B响应确认的写回。编译器生成完整执行段、CPU算子交接和可读任务表；FC→激活融合保留FC INT8边界。仅结构、整数语义、范围和权重布局全部匹配时考虑MODE0，并根据已测启动/搬运开销选择。启动一次不等于只有一条FC描述符，描述符也不等于64B权重tile。

功能检查点：7,600个缩放向量；25组任务尺寸/激活/非法描述符，另有DMA读写错误、重试和6个执行阶段复位；原41组及单双层切换通过。新增RTL下原四样本完整SoC仍2700拍。原8组模型也完成真实CPU/AXI/SRAM运行，所有整数参考与冻结基准一致；额外13种模型配置及两种新CPU激活内核通过完整SoC。融合/内部张量使用被动观测逐值核对，物化张量仍用Debug SBA读回。

首轮新通用路径：mixed0 3724→2548拍、wide0 2044→1042拍、output_tiled0 1959→906拍；trained_har通用任务路径4019→1727拍。单样本强选合法特化路径测得1768拍，因此后续成本策略优先通用任务；四样本匹配样例特化3182拍、同整数通用任务3616拍。这些生成程序不同于原始2700拍专用固件。小型CPU后接单独激活曾496→511拍，因此加入小算子保留CPU策略，最终表需重新跑稳定版本。

[功能检查点证据](functional/index.json)。旧MMIO和MODE=0保持；原始2700拍为目标，2835拍为硬上限。新增面积0.03～0.05mm²是规划目标，尚无本轮面积测量。没有新增PNR、SDF或Lab5通过结论。

基准目录保存程序、参考、实际输出、生成bench、原始日志、无损压缩逐拍trace及SHA。source_at_measurement保存测量工具原始文本，未来工具修改不改写这些证据。早期无效ID-PC归属和汇总正则问题的原运行仍在ignored runs中，最终表仅采用已校正版本。
