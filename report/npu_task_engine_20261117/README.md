混合网络的3719个硬件周期中，NPU ISSUE24、权重未就绪176、就绪控制15；CPU输入/bias/结果搬运622、配置/启动82、量化循环550、激活阶段1070、逐元素阶段1118，其余62。各项按已接收指令时间边界及NPU状态分账，不把CPU量化等同于纯乘法器忙周期。R数据未返回与权重未就绪交集39拍，不能把176拍全部称为AXI读等待。原专用NPU952拍则为ISSUE576、量化128、排空2、Argmax20、权重未就绪192、就绪控制34。

1→1单任务现有NPU175拍、CPU105拍，说明小尺寸需要保留CPU后端选择。具体流量区分CPU有效字节、SRAM32位实际命令、DMA两端及逐张量次数，避免重复加总。
