# 面积比较和收紧

同一TT综合配置：Genus19.17、native library enable、自动ICG开启、TT非负表组合单元映射，原生8KiB SRAM不变。这里的Cell Area包含SRAM，不包含后续PAD/filler/时钟树等物理开销；不能与布局后的空闲行面积直接相减。

| 版本 | Cell Area mm² | Cells | ICG | 与接受基线增量 mm² |
| --- | ---: | ---: | ---: | ---: |
| 接受基线346e467 | 2.124368263 | 68521 | 446 | 0 |
| 首轮任务引擎，直接LUT，d05f615 | 2.293185728 | 75671 | 609 | 0.168817465 |
| 同轮候选4B缓存，647f746 | 2.293673063 | 75651 | 610 | 0.169304800 |

缓存相对直接方案增加0.000487335mm²，这是整设计两次映射的净差，包含映射/缓冲变化，不能解释为某12个FF的独立物理面积。两轮均0 latch、原生SRAM1个、叶单元都有模型、被排除的TT组合单元0。

根据 [访问实测](../lut_comparison/README.md)，保留复用32位落地寄存器的一字缓存，默认硬件参数TASK_LUT_WORD_CACHE=1；描述符仍可关闭缓存。没有增加256B寄存器阵列。

**首轮整体面积超过0.155mm²保守预算，不能作为最终版接受。** 已实施以下功能等价收紧，需重新综合测量：

- h缓冲统一为一个字节写端口；旧MMIO隐藏值和新打包读窗口共用一个32位选择器。
- ACT只需要读取每样本前32个INT8，避免为K=64输入区额外生成完整读选择器；FC装载和计算仍保留K≤64。
- 描述符保留位随DMA到达即检查，用一个错误位记录，不保存115位无效内容；使用严格地址顺序与总数检查取代重复位图。
- 接受的表地址仅保存8KiB内偏移，sample/index/内部字计数按合法上限收窄；保留原32位BASE/COUNT读回和非法地址检查。
- 精确缩放改为MSB优先Horner式四次字节乘加，取消移位到不同字节位置的宽选择器；shift≤24时，舍入后超出INT32的值必然饱和，只给32位做可变右移，宽乘积及舍入仍保留54位。

收紧后11,788组独立整数向量（增加INT32/INT8阈值和每种shift边界）、两种缓存配置任务测试、原41组及单双层切换通过；原四样本全SoC仍2700拍。七个后仿模型的镜像/校验清单已在RTL整SoC逐字验证，包括内部打包读窗口、专用隐藏缓冲、跨K/N及深层链。四个完整SoC执行中复位场景（POR在描述符/查表阶段、真实DMCONTROL NDM在FC/输出阶段）均撤销有效上下文，重新装载整个镜像后逐值通过。尚无收紧后的面积或新PNR/SDF/Lab5结论。

服务器来源：direct_first内source.json/input_manifest.json；缓存比较原始证据保存在cache_first。后续实现必须使用收紧后独立上传，保留这些超预算原始结果。
