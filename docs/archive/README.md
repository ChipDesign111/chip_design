# Historical records

此目录保存早期课程规划、成员协作安排、分支整合与辅助开发记录。它们反映当时的状态，可能包含已失效的计划或相对时间，不作为现行工程规范。

- [project-setup/plan.md](project-setup/plan.md)：初始计划
- [project-setup/backlog.md](project-setup/backlog.md)：初始待办
- [project-setup/team.md](project-setup/team.md)：初始协作安排
- [project-setup/decisions.md](project-setup/decisions.md)：早期决策
- [project-setup/sources.md](project-setup/sources.md)：早期来源核对
- [project-setup/branch-review.md](project-setup/branch-review.md)：分支整合记录
- [ai-log/](ai-log/README.md)：辅助开发记录
- [weekly/](weekly/README.md)：早期周报模板

现行入口为 [工程文档](../README.md)、[ADR](../adr/README.md)、[路线图](../roadmap.md) 和 [验证报告](../../reports/README.md)。
