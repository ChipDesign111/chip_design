# 组织与协作

共有位置：ChipDesign111/chip_design。组织创建和仓库选择已经由用户完成；其他成员账号待收集。
当前不进行四人技术任务分配。

## 建议组织配置

- 每人使用个人账号加入组织，四人组成 chip-team。
- 给团队仓库 Write 权限；建议两位 Owner 负责管理和交接。
- 成员邀请需确认实际 GitHub 用户名，不能猜测账号。
- 没有配置前，不声称团队权限或分支保护已完成。
- main 经 PR 和至少一名非作者复核；使用当前套餐支持的分支规则时再落地。
- 看板：待开始、进行中、待验证、完成。

## 周期

每周开始确定任务和依赖；周中同步接口；周末对同一 commit 做共同验收。
个人学习目录、工具路径和临时调试文件不直接进入共有仓库。
[贡献规范](../CONTRIBUTING.md) 和 [任务清单](backlog.md) 是统一入口。
