## CPU 主存

已核对的 Lab 3 模板采用 8 KB 主 SRAM；链接脚本栈顶/测试标志在 0x80001FE0 附近。
共有平台以最终导入版本为准，地址规则的大 LENGTH 不表示实际容量。

必须预算：text、rodata、data、bss、栈、测试状态区。模型在 CPU 侧的副本与 NPU 本地数据都要计算。
首版：INT8 保存权重，一次少量输入，避免完整测试集入程序和大型 printf 库；使用裸机状态记录。
当前 RV32I 六样本自检使用 6232 字节（2336 指令 + 3896 数据），无函数调用栈或运行库；0x1FE0–0x1FFF 保留测试标志。生成器对超限直接报错。后续 C 版本必须重新预算。
每次软件构建保存 size 和 map 摘要，确认 bss/堆栈不碰撞。超限时重评程序或存储，不能只改链接脚本。

## NPU 本地窗口

Lab 3 包装层 addr[13:2] 是 12 位 word 地址，覆盖 16 KB，其他高位可能产生别名。
[MMIO 草案](mmio.md) 内最高数据结束 0x0B18，未超出窗口。
只有合法范围可访问；课程宏、复位、运行时装载及 FPGA 替换均待验证。
