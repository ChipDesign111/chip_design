# Memory budget

## 模型与工作数据

| 内容 | 位宽 | 单样本字节数 | 双样本批次字节数 |
| --- | --- | ---: | ---: |
| 两层权重 2240 个，共享 | INT8 | 2240 | 2240 |
| 两层偏置 38 个，共享 | INT32 | 152 | 152 |
| 输入 | INT8 | 64 | 128 |
| hidden | INT8 | 32 | 64 |
| score | INT32 | 24 | 48 |
| 合计，不含控制/类别/对齐 | | 2512 | 2632 |

这些是有效数据量，不能直接换算为宏容量或面积。权重实现包含 38 个同步 bank、76 个读端口及 560 个 word 有效位；输入、偏置、中间值和结果为小型寄存器文件。映射到 FPGA BRAM 或 ASIC SRAM 的资源仍需目标综合验证。

## CPU 主存

冻结参考平台的主 SRAM 为 8192 B。测试状态保留区为 `0x80001FE0–0x80001FFF`；地址译码中的大区间不表示实际 SRAM 容量。

| 自检镜像 | 总字节数 | 内容 |
| --- | ---: | --- |
| Tiled 合成参数，8 次推理 | 6904 | 2948 B 指令 + 3956 B 数据 |
| 同工作量性能比较，6 次推理 | 6908 | 用于与历史基线比较 |
| 真实模型，24 条输入 / 12 个批次 | 6232 | 768 B 指令 + 5464 B 数据 |

当前生成器使用裸机 RV32I 指令，无函数调用栈或运行库，并检查镜像与保留区边界。后续引入 C 驱动、堆栈或运行库必须重新核对 text、rodata、data、bss、堆栈与测试状态的占用。超限需要调整软件或真实存储设计。

## NPU 本地窗口

参考包装层使用 `addr[13:2]` 形成 12 位 word 地址，可寻址 16 KiB。高位截断会产生地址别名，软件只访问基址 `0x70000000` 加合法偏移。

[MMIO 地址表](mmio.md) 中最高有效窗口结束于 `0x0C9C`，包含第二样本的类别寄存器。`configs/project.json` 与仓库检查覆盖窗口对齐、重叠和越界。

权重逻辑复位、同步读、运行中写保护及 CPU 装载均有仿真覆盖。目标存储宏、板级行为和物理实现属于后续验证范围。
