# Engineering roadmap

路线图按能力与交付条件组织，不绑定成员或课程周次。工作项在 Issues 中维护。

| 优先级 | 方向 | 完成条件 |
| --- | --- | --- |
| P0 | 目标硬件与约束基线 | 板卡/工艺、时钟、I/O、存储资源及工具版本明确 |
| P0 | 可复现发布 | 固定工具与输入、独立环境复现、版本化证据清单 |
| P1 | 目标存储映射 | bank 映射、端口/复位语义、资源与时序报告，功能回归通过 |
| P1 | C/GCC 驱动链 | 从源到 ELF/map/hex 可构建，真实 CPU 测试和 SRAM 预算完整 |
| P1 | FPGA 原型 | 时钟/引脚约束、实现报告、真实输入上板结果一致 |
| P1 | 模型评估改进 | 保留独立验证划分，降低坐/站混淆，硬件契约和精度回归 |
| P2 | 更长流与搬运优化 | DMA/队列协议、带宽测量、吞吐收益与回归证据 |
| P2 | ASIC 实现 | 工艺授权环境、综合/布局布线/STA/物理签核及一致版本归档 |

当前已具备 tiled RTL、banked 权重、双样本流水、已选模型验证、完整 SoC 仿真和通用综合结构检查。缺口及能力状态见 [规格](spec.md)。

优化以可测瓶颈为依据。核心周期比和端到端周期比分别报告；目标频率、功耗、面积不由 RTL 周期推断。历史排期保留在 [归档](archive/README.md)。
