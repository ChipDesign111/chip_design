# HAR 设计规格

状态：tiled V2 与已选训练模型已完成仿真联调；2026-10-13。算术沿用 V1，双样本流水/MMIO 见 tiled-npu.md；模型实测见 model-verification.md。外围固定为 Lab 3，仅 NPU 可变，FPGA/ASIC 待完成。

## 功能

- 64 维已预处理 INT8 特征输入。
- 两层 MLP：64→32→6，含两层偏置。
- 第一层 ReLU 和重新量化，第二层六个同尺度 INT32 得分。
- Argmax 输出 0–5；首版不要求推理 Softmax。
- CPU 通过 MMIO 装载参数和输入、启动、轮询、读回。
- 参数装载后可多次推理复用。
- V2 一次命令支持 1 或 2 样本；两级各样本活跃 19 拍，单次 39 拍、双次 59 拍。批次共享权重/偏置/量化，双输入、隐藏和结果分开存储；无 DMA 或无限长流。

编号按 UCI HAR 标签减 1：0 步行、1 上楼、2 下楼、3 坐、4 站立、5 躺卧。见 [model/training](../model/training/README.md)。

## V1 数值格式

输入/权重 INT8，偏置/累加 INT32，第一层激活有符号 INT8 中的 0–127，输出得分 INT32。
详细规则见 [numerics.md](numerics.md)。INT8 的有效取值范围、量化尺度及舍入必须随模型版本导出。

## 首版范围

主机完成数据预处理；NPU 执行整个两层网络。
不预先加入 DMA、多时钟域、可变网络、传感器采集或批量流水线。
先建立可验证 V1，再按实际瓶颈评估优化。
