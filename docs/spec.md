# Functional specification

## 工作负载

固定拓扑 `64 → 32 → 6`，共 2278 参数、每输入 2240 MAC。输入为已预处理的 64 维 INT8 特征；两层带偏置，第一层执行 ReLU/重新量化，第二层保留有符号得分并执行 Argmax。

| 数据 | 类型 / 范围 |
| --- | --- |
| 输入与权重 | INT8，-128..127 |
| 偏置、累加、输出得分 | INT32；合法输入不允许累加溢出 |
| hidden | 0..127 |
| 类别 | 0..5；相等得分取最小下标 |

标签沿用 UCI HAR：0 步行、1 上楼、2 下楼、3 坐、4 站立、5 躺卧。真实模型特征下标、输入尺度、偏置及量化参数由 `model/export/` 定义。

## 控制与数据生命周期

CPU 通过 [MMIO](mmio.md) 装载参数和输入，启动计算，带超时轮询完成并读取结果。批长度为 1 或 2；一批共享权重、偏置和量化配置，分别保存输入/hidden/结果。参数可跨命令复用。

BUSY 时写请求被拒绝并置 ERROR。DONE 保持到 START、ACK 或复位。复位中断当前计算并清逻辑数据有效性；随后重新装载模型。状态读无副作用，读结果须在 DONE 后使用。

## 能力状态

| 能力 | 状态 |
| --- | --- |
| 整数算术 / tiled RTL / 同步 bank 存储 | 已实现并仿真验证 |
| 已选训练模型逐值对照 | 全 2947 条测试输入通过 |
| 真实 CV32E40P / AXI / NPU 仿真 | 已验证，含六类 24 条真实输入 |
| 通用综合结构 | 已检查；不包含目标时序/面积 |
| C/GCC 驱动链 | 未交付；当前使用 RV32I 自检生成器 |
| 传感器采集、原始信号特征提取、DMA、无限长队列 | 不在当前范围 |
| FPGA、目标工艺综合、STA、物理签核 | 未验证 |

## 兼容性

冻结参考平台接口保持不变。内部调度或存储可以重构，但须保持已声明的算术与外部时序；修改寄存器、位宽或舍入规则时提供兼容说明，联动参考、固件、向量和测试。

当前核心延迟为 39 / 59 周期（单 / 双输入），计数语义见 [MMIO](mmio.md)。这些数值是仿真周期，不构成目标频率承诺。验证依据见 [报告目录](../reports/README.md)。
