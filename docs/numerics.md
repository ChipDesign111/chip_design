# 整数数值规则草案

状态：DRAFT。基线权重已在 [model/export](../model/export/README.md)，整数尺度以 [quant_params.json](../model/export/quant_params.json) 为准；RTL 逐值对照仍未完成。

## 计算定义

第一层：
`acc1[j] = bias1[j] + sum(weight1[j][i] * input[i])`，i=0..63，j=0..31。
`hidden[j] = clip(requant(max(acc1[j], 0)), 0, 127)`。

第二层：
`score[k] = bias2[k] + sum(weight2[k][j] * hidden[j])`，j=0..31，k=0..5。
类别取最大 score 的下标；相同得分建议取最小下标。

所有乘法先按有符号解释；加入累加器前显式符号扩展。中间运算不能因表达式位宽提前截断。
INT32 累加不是对任意 INT32 偏置都自动安全：导出器必须检查允许输入、权重和偏置的界限。

## 建议量化

- 首版每层统一权重尺度、输入/隐藏层统一尺度，零点采用 0 的对称方案。
- 偏置转换到对应输入尺度×权重尺度的累加尺度。
- 第一层重新量化采用固定整数规则；若尺度比例是 2 的幂可只用移位，否则评估乘整数系数再移位。
- 乘整数系数时扩大中间位宽，并明确舍入、饱和和参数范围。
- 对已 ReLU 的非负数，右移 s>0 可采用 `(value + 2^(s-1)) >> s`；s=0 单独处理，乘系数路径的 value 含义另行固定。
- 第二层所有得分必须对应同一个正比例尺度。每输出通道尺度不同的整数不能直接 Argmax。
- 不在第二层做 ReLU，以免改变分类顺序。

## 参数导出必须包含

模型版本、输入归一化/量化方式、权重排列、两层尺度、偏置整数值、重新量化系数和移位、有效范围、标签映射、舍入规则。
导出的向量要给出 32 个 hidden、六个 score 和 class_id。

## 算法质量与实现质量

浮点模型与整数模型可能有精度损失，报告真实测试集上的准确率差异。
RTL 和已冻结整数模型要求逐值一致；不能只比较最终类别，也不能把合成输入的 PASS 当作分类准确率。
