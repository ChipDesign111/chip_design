# Integer arithmetic contract

状态：当前 INT8 tile DMA 实现；训练模型来自 [model/export](export/README.md)，参数以 [quant_params.json](export/quant_params.json) 为准。实际 MULT=1064、SHIFT=20、舍入加数 524288，均在当前硬件支持范围，无需改动 RTL。

## 计算定义

第一层：
`acc1[j] = wrap22(bias1[j] + sum(weight1[j][i] * input[i]))`，i=0..63，j=0..31。
`hidden[j] = clip(requant(max(acc1[j], 0)), 0, 127)`。

第二层：
`score[k] = wrap22(bias2[k] + sum(weight2[k][j] * hidden[j]))`，j=0..31，k=0..5。
类别取最大有符号 score 下标；平局取最小下标。第二层不做 ReLU。

输入和两层权重为 -128..127。MMIO 的偏置仍占 32 位字，但硬件把低 22 位解释为有符号 bias；累加器 `a1/a2` 为 signed 22 位，每次乘积累加按二进制补码回绕。合法配置必须把偏置符号扩展到 32 位并保证其落在 `[-2^21, 2^21-1]`。训练模型应避免溢出，导出时检查偏置及允许输入范围的界限，不能依靠回绕改善模型结果。

任意 INT8 输入和权重的无偏置理论范围为：FC1 `[-1,040,384, 1,048,576]`，FC2 `[-520,192, 524,288]`。当前训练 bias 使 FC1 的通用上界为 `1,053,628`、下界为 `-1,042,502`，均落在 signed 22 位范围 `[-2,097,152, 2,097,151]` 内。

第一层定义 value=max(acc,0)×MULT，MULT=0..65535；s=SHIFT=0..31。
若 s=0，rounded=value；否则 rounded=(value+2^(s-1))>>s。使用 38 位非负中间值（足以容纳正 INT22×UINT16 与最大舍入加数），hidden=min(127,rounded)。MULT=0 得到零，正数平局向上舍入。默认 MULT=1、SHIFT=0。
输入和 hidden 为零点 0；两层得分需同一正比例尺度，才能直接 Argmax。逐项参考位于 model/reference/mlp_int.py。

所有乘法先按有符号解释；加入累加器前显式符号扩展。中间运算不能因表达式位宽提前截断。
INT22 累加不是对任意 32 位偏置都自动安全：导出器必须检查允许输入、权重和偏置的界限。当前随机回归覆盖 22 位补码正负极值及其回绕，不再接受 `INT32_MIN/MAX` bias 作为可精确表示的输入。

## 模型导出约束

- 当前模型每层统一权重尺度、输入/隐藏层统一尺度，零点采用 0 的对称方案。
- 偏置转换到对应输入尺度×权重尺度的累加尺度。
- 第一层重新量化采用固定整数规则；若尺度比例是 2 的幂可只用移位，否则评估乘整数系数再移位。
- 乘整数系数时扩大中间位宽，并明确舍入、饱和和参数范围。
- 对已 ReLU 的非负数，右移 s>0 可采用 `(value + 2^(s-1)) >> s`；s=0 单独处理，乘系数路径的 value 含义另行固定。
- 第二层所有得分必须对应同一个正比例尺度。每输出通道尺度不同的整数不能直接 Argmax。
- 不在第二层做 ReLU，以免改变分类顺序。

## 参数导出必须包含

模型版本、输入归一化/量化方式、权重排列、两层尺度、偏置整数值、重新量化系数和移位、有效范围、标签映射、舍入规则。
导出的向量要给出 32 个 hidden、六个 score 和 class_id。

## 算法质量与实现质量

浮点模型与整数模型可能有精度损失，报告真实测试集上的准确率差异。
RTL 和已冻结整数模型要求逐值一致；不能只比较最终类别，也不能把合成输入的 PASS 当作分类准确率。
